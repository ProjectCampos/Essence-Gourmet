# 🍬 Essence Gourmet

> **Projeto Acadêmico:** Atividade prática para a disciplina de Algoritmos e Lógica de Programação.

Uma loja de doces artesanais com design minimalista, focado em uma experiência de usuário intuitiva e funcionalidade real de e-commerce.

## 🌐 Acesse o site

**[👉 Abrir Essence Gourmet](https://projectcampos.github.io/Essence-Gourmet/)**

---

## 🎨 Identidade Visual
O design foi pensado para transmitir sofisticação e conforto, utilizando tons terrosos e neutros:
* **Bege:** Fundo e suavidade.
* **Marrom Chocolate:** Tipografia e botões de ação.
* **Branco:** Áreas de destaque e respiro.

## 🚀 Funcionalidades
- [x] **Catálogo Dinâmico:** Lista de produtos gerada via JavaScript.
- [x] **Carrinho de Compras:** Adição de itens com lógica de soma automática.
- [x] **Totalizador:** Cálculo do valor total da compra em tempo real.
- [x] **Design Responsivo:** Adaptado para celulares e desktop.

## 🧠 Lógica de Programação Aplicada
Neste projeto, foram aplicados conceitos fundamentais de algoritmos:
1.  **Estruturas de Dados:** Uso de Arrays de Objetos para armazenar as informações dos doces.
2.  **Manipulação do DOM:** Interatividade entre o utilizador e a página (cliques e atualizações de texto).
3.  **Event Listeners:** Captura de eventos para processar as escolhas do cliente.
4.  **Cálculos Aritméticos:** Algoritmo para somar preços e quantidades no carrinho.
